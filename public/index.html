BYTE BACK 탈환 작전실 & 자료실

판정기 규칙, 탐지 사건, 회수 상태, 복구 버전 요약 및 실제 API 연동 상태와 가린 서버 기록 대시보드입니다.

⚔️ 탈환 작전실 관제 현황

12단계 실시간 관제
🛡️ 판정기 규칙 3건 적용
3개 규칙 활성
  • • device_registered (기기 등록/소유자 검증)
  • • step_up_required (복합 이상 접속 Step-up)
  • • zone_rule (자료·공지 구역 격리 및 쿼리 차단)
상태: ZTNA 정책 적용 완료
🔍 탐지 사건 운영 반 엔진: 미실행
임계치 120건 / 10분
  • • 감시 사건: GET 요청 폭주 (burst_read)
  • • 로컬 가상 사건: 6건 테스트 통과 확인
  • • 운영 반 엔진 연동: 미실행 (심판 검증 대상)
출처: docs/DETECT_EVENTS.md 규격
⚠️ 회수 상태 자동 회수: 미실행
권한 상태: observe
  • • 기본 판정: 정상 관찰 (observe)
  • • 임계치 초과 시: propose_revocation 제안
  • • 자동 접속 회수: 미실행 (제안 반환 전용)
방식: 세션/권한 회수 제안 체계
🔄 복구 버전 복원 실행: 미실행 (대기)
복원 경로: POST /api/restore
  • • 메모 복원: SHA-256 해시 대조 & dryRun 지원
  • • 정책 복원 도구: npm run policy:restore
  • • 실제 복원 쓰기: 미실행 (대기)
※ 가상 메모 본문은 비공개 보호됩니다.
