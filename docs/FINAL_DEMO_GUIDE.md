# 케셰브 시연 순서 및 최종 결과 명세서

## 1. 개요 및 작전 정의

* **화면 틀**: 관제 대시보드형을 적용했습니다. 상단에 4대 관제 지표 카드를 배치했습니다. 하단에 스냅샷 변동률 추이와 실시간 감사 패널을 배치했습니다.
* **실행 형태**: 포장 없이 프로젝트 폴더에서 직접 실행합니다. 패키징 빌드 명령은 실행하지 않습니다. 설치 프로그램은 과정 종료 후 참고 자료로 활용합니다.
* **기준 커밋**: `c84f6428cf0d66f54169a221200fa9fb27142ffd`

## 2. 제공 기능과 학생 구현 기능 분리

프레임워크 무결성을 유지하기 위해 제공 코드와 학생 구현 코드를 분리했습니다.

| 구분 | 컴포넌트 및 파일 | 상세 역할 |
|---|---|---|
| **제공 기능** | 로컬 HTTP 라우팅 (`src/server.mjs`) | 정적 파일 서빙 및 기본 API 라우팅을 담당합니다. |
| **제공 기능** | 외부 서버 통신 모듈 (`src/engine/sdp-host.mjs`) | 외부 SDP 서버와의 클라이언트 인증서 기반 HTTPS 통신 규격을 제공합니다. |
| **제공 기능** | AI 게이트웨이 연동 (`src/ai/service.mjs`) | 수업용 AI 게이트웨이 인증과 모델 목록 조회를 처리합니다. |
| **제공 기능** | 실행 검증 도구 (`tools/start-alekov.ps1`) | 노드 버전 검사, 포트 점유 확인, 런타임 인터셉터 연결을 수행합니다. |
| **학생 구현** | 관제 대시보드 화면 (`student/extension.mjs`) | 상단 4대 관제 카드와 하단 2단 분할 레이아웃을 렌더링합니다. |

| **학생 구현** | 모의 조치 엔진 (`/api/actions/*`) | 조치 발급, 상태 전이, SHA-256 영수증 해시 검증을 처리합니다. |

## 3. 핵심 기능 3가지 시연 순서

### 시연 1. 종합 관제 대시보드 상단 4대 카드 및 단말 읽기 전용 실측값 확인
1. 터미널에서 실행 스크립트를 구동합니다.
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo
   ```
2. 브라우저로 `http://127.0.0.1:5189/`에 접속합니다.
3. 상단 탭에서 **[종합 관제 대시보드]**를 선택합니다.
4. 상단 4대 카드의 데이터를 확인합니다.
   * **카드 1 (네트워크 어댑터)**: 활성 어댑터 4개 실측 데이터를 확인합니다. 주소(`192.168.3.2/24`), 게이트웨이(`192.168.3.1`), DNS(`168.126.63.1, 168.126.63.2`)를 표기합니다.
   * **카드 2 (방화벽 설정)**: 도메인, 개인, 공용 3개 프로필 활성 상태를 확인합니다. 인바운드 차단과 아웃바운드 허용 기본 동작을 확인합니다. 읽기 전용 배지를 표기하며 시스템 설정을 변경하지 않습니다.
   * **카드 3 (윈도우 일반 기록)**: 최근 24시간 이벤트 로그 건수를 확인합니다. 시스템 11건, 애플리케이션 6건 집계를 표기합니다. 침해 공격 탐지 결과가 아니라는 비침해 고지 배너를 표기합니다.
   * **카드 4 (하드웨어 자원)**: CPU 16코어, 메모리 15.84 GB, 디스크 465.65 GB 실측 수치를 확인합니다.

### 시연 2. 하단 2단 분할 영역의 변동률 추이 및 실시간 감사 패널 검증
1. 하단 좌측 영역을 확인합니다.
   * 직전 스냅샷 대비 CPU, 메모리, 네트워크 변동률(Δ) 수치를 확인합니다.
   * 실시간 이벤트 스트림 수신 상태를 확인합니다.
2. 하단 우측 영역을 확인합니다.
   * 단말 점검 카드에서 방화벽 읽기 전용 유지 상태와 일반 권한 검사 결과를 확인합니다.
   * 실시간 감사 패널에서 기준선 스냅샷 저장 버튼을 클릭합니다. 기준선 캡처 완료 메시지를 확인합니다.
   * 감사 보고서 검증 버튼을 클릭합니다. SHA-256 무결성 검증 성공 결과를 확인합니다.

### 시연 3. 가상 보안 사건 분석, 로컬 AI 설명 보고서, 조치 영수증 검증
1. 가상 보안 사건 목록에서 `event-01` 항목을 선택합니다.
2. 사건 상세 영역을 확인합니다.
   * 단말 네트워크 및 방화벽 실측 수치가 반영된 로컬 AI 사건 설명 보고서를 확인합니다.
   * 해당 설명에 `[예시값]` 배지가 표기되어 있는지 확인합니다.
3. 조치 버튼을 클릭합니다.
   * 조치 상태가 준비(`prepared`)에서 대기(`pending`)를 거쳐 완료(`succeeded`)로 전이하는 과정을 확인합니다.
   * 화면에 발급된 영수증 식별자와 SHA-256 해시 값이 일치하는지 확인합니다.

## 4. 한계 및 확인 불가 항목

* **관리자 권한 전용 로그**: 윈도우 보안 감사 로그와 방화벽 패킷 차단 로그는 일반 권한에서 읽을 수 없습니다. 설정을 강제로 바꾸지 않고 `「확인 불가」` 배지와 사유를 표시합니다.
* **외부 서버 미연결**: 외부 SDP 릴레이 서버 설정을 주입하지 않은 단독 기동 상태입니다. 설계된 안전 분기에 따라 `「SDP 미연결」` 배지를 표기합니다.
* **운영 환경 원천 조치 미집행**: 단말 네트워크를 실제로 차단하거나 계정을 잠그지 않습니다. 안전한 검증 환경을 위해 모의 라이프사이클과 영수증 해시 검증 단계까지만 실행합니다.
* **승인 외 패키지 취약점 스캔**: 화이트리스트 8종 외의 미승인 라이브러리는 외부 조회를 차단하고 미조회 상태로 안전하게 유지합니다.

## 6. 단말 [실측값] vs [예시값] 구분 기준

| 구분 배지 | 대상 항목 | 단말에서 확인된 실제 값 / 표시 내용 | 비고 |
|---|---|---|---|
| **`[실측값]`** | 단말 네트워크 구성 | 활성 어댑터 4개 (이더넷 `192.168.3.2/24`, 게이트웨이 `192.168.3.1`, DNS `168.126.63.1, 168.126.63.2`, 가상 어댑터 3개) | 일반 권한 읽기 전용 실측 |
| **`[실측값]`** | 단말 방화벽 설정 | Domain, Private, Public 3개 프로필 켜짐 (인바운드 차단, 아웃바운드 허용) | **읽기 전용 (설정 변경 안 함)** |
| **`[실측값]`** | 최근 24시간 윈도우 로그 | System 오류 2건·경고 9건, Application 오류 0건·경고 6건 | **「이 건수는 침해나 공격 탐지 결과가 아닙니다」** 명시 |
| **`[실측값]`** | 단말 하드웨어 자원 | CPU 16코어, 메모리 15.84 GB, 디스크 465.65 GB | `node:os`, `statfsSync` 실측 |
| **`[예시값]`** | 데모 모드(`--demo`) 데이터 | 가상 업무 앱 3종(`allow`, `deny`, `challenge`), 가상 보안 사건 1건(`event-01`) | 실제 조회가 아닌 설명용 가상 데이터 |
| **`[예시값]`** | 로컬 AI 설명 및 조치 라이프사이클 | 단말 실측 요약 기반 사건 원인 설명, 보안 조치(`ac-on-...`) 라이프사이클 및 영수증 | 가상 사건 기반 설명용 생성 데이터 |
| **`「확인 불가」`** | 관리자 권한 전용 항목 | 윈도우 보안 감사 로그, 방화벽 패킷 차단 로그(`pfirewall.log`) | 권한 부족 시 설정 변경 없이 사유 표시 |
| **`「SDP 미연결」`** | 외부 SDP 릴레이 서버 상태 | 기본 실행 및 데모 실행 모두 외부 서버 미연결 상태 표기 | 단말 실측값과 명확히 분리 표기 |

## 7. 실행 명령어 및 점검 절차

### 실행 명령어 (on-client 폴더)
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo
```
*(직접 실행 시: `node --import ./student/pc-status-runtime.mjs src/server.mjs --demo`)*

### 브라우저 확인 절차
1. `http://127.0.0.1:5189/`에 접속합니다.
2. 상단 네비게이션에서 **[종합 관제 대시보드]** 탭을 클릭합니다.
3. 상단 4대 관제 카드의 실측값 배지와 단말 데이터를 확인합니다.
4. 하단 좌측의 변동률 추이와 우측의 무결성 감사 패널 결과를 확인합니다.
